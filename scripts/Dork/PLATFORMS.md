## 🎯 How It Works

When you use **Person Search** or **Social Media Deep Dive**, the script automatically:

1. Takes your input (name/username)
2. Generates dork queries for ALL these platforms
3. You copy/paste each into Google
4. Find results across the entire digital landscape

### Example Output:

```
Enter username: johndoe123

Generated 150+ Google Dorks:
1. "johndoe123" site:facebook.com
2. "johndoe123" site:instagram.com
3. "johndoe123" site:roblox.com
4. "johndoe123" site:discord.com
5. "johndoe123" site:telegram.org
... (150+ more searches)
```
